# HollywoodAI - Movie Summary AI Application

<img width="1440" alt="HollywoodAI Image" src="https://i.postimg.cc/xjm11Td4/Hollywood-AI-App.png">

Created and launched an intuitive platform for AI-driven film summaries using Next.js, TypeScript, and Firebase.

## Install Packages

```bash
npm i
```

## Setup .env file

```bash
NEXT_PUBLIC_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=
GOOGLE_APPLICATION_CREDENTIALS=

```
## Start the app

```bash
npm run dev
```
